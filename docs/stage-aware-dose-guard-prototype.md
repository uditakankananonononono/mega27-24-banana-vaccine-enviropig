# Banana stage-aware dose guard, first prototype

The proposed invention is a source-scoped evidence tool that treats material, moisture basis, analyte, batch and measurement stage as different dimensions of a dose claim. On six transparent, constructed regression cases it reproduces the published [Chan 2013 banana-leaf line 4](https://onlinelibrary.wiley.com/doi/10.1111/pbi.12015) nominal 50 g x 257.6 ng/g = 12.88 µg, and the published [lettuce VLP batch IV](https://pmc.ncbi.nlm.nih.gov/articles/PMC4209752/) nominal 1.72 mg x 29 µg/g dry weight = 49.88 ng, rounding to its printed 50 ng. It refuses a leaf-to-fruit transfer, a total-immunoreactive-antigen-to-assembled-VLP transfer, and a processing-content-to-post-digestion transfer. A banana fruit post-digestion antigen request returns **no matched measurement**, not a point estimate. All cases retain `intestinal_surviving_ug = null`.

This prototype does not recommend a construct, antigen, formulation or production change. The cases were built after source inspection, so the refusal count is only a regression demonstration, not a held-out benchmark or proof of new method. Stage-specific potency and plant-antigen stability analyses are prior art; the newness of this combination is untested. The locked task still needs actual banana-fruit protein and matched digestive intactness measurements plus an independent comparator cohort. No discovery or project gate credit.
